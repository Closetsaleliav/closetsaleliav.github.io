# Closet Sale

Página de pedidos Black Friday y encargos de EE.UU. a Colombia (@closetsaleliav).

- `index.html`: página completa, sin dependencias salvo las fuentes de Google.
- Pedido mínimo y fecha límite de listas: variables `MIN_ORDER_USD` y `CLOSE_AT` al inicio del script.
- Para publicarla: Settings > Pages > Deploy from a branch > `main` / root.
