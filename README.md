# Closet Sale Liav

Página de pedidos Black Friday y encargos de EE.UU. a Colombia (@closetsaleliav).

- `index.html`: página completa, sin dependencias salvo las fuentes de Google (Instrument Serif, Yellowtail y Quicksand).
- Colores: verde matcha oscuro #36601F (principal) · Cherry #670626 (acento) · Matcha #BAD797 (suave) · fondo hueso claro #FBF8F1.
- Pedido mínimo y cierre de ofertas: variables `MIN_ORDER_USD` y `CLOSE_AT` al inicio del script.
- Para publicarla: Settings > Pages > Deploy from a branch > `main` / root.
